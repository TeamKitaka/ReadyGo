==============================================

핵심요구사항) 게임 선택 모달 컴포넌트를 구현할 것.

핵심요구사항) Props 타입 정의
            interface GameSelectModalProps {
                isOpen: boolean;
                onClose: () => void;
                onConfirm: (appId: number) => void;
                games: Array<{ app_id: number; name: string }>;
                selectedGame: { app_id: number; name: string } | null;
                onSelectGame: (game: { app_id: number; name: string }) => void;
                searchQuery: string;
                onSearchChange: (query: string) => void;
                loading?: boolean;
            }

핵심요구사항) 컴포넌트 구조
            1) 모달 오버레이
                - <Overlay /> 공통 컴포넌트 사용
                - 클릭 시 onClose 호출
                - 모달이 열려있을 때만 표시

            2) 모달 컨텐츠 영역
                - 중앙 정렬
                - party-submit의 gameOptionsGroup 스타일 참고
                - 적절한 크기 및 패딩 설정

            3) 게임 검색 영역
                - <SearchBar /> 공통 컴포넌트 사용
                - searchQuery를 value로 사용
                - onSearchChange로 검색어 변경 처리
                - party-submit의 게임 검색 UI 참고

            4) 게임 목록 영역
                - filteredGames 또는 games 목록 표시
                - 각 게임 항목 클릭 시 onSelectGame 호출
                - 선택된 게임은 시각적으로 구분 (배경색 또는 border)
                - 스크롤 가능한 목록 (게임이 많을 경우)
                - 로딩 상태일 때 스켈레톤 또는 로딩 스피너 표시

            5) 모달 하단 버튼 영역
                - 확인 버튼: <Button /> 사용, variant: primary, 클릭 시 onConfirm(selectedGame.app_id) 호출
                - 취소 버튼: <Button /> 사용, variant: secondary, 클릭 시 onClose 호출
                - 선택된 게임이 없으면 확인 버튼 비활성화

핵심요구사항) 스타일링
            - 색상: global.css에 명시된 CSS 변수 토큰 활용 (하드코딩 금지)
            - 타이포그래피: global.css에 명시된 CSS 변수 토큰 활용 (하드코딩 금지)
            - party-submit의 gameOptionsGroup 스타일 참고하여 구현
            - 모달은 중앙 정렬, 적절한 최대 너비 설정
            - 게임 목록은 스크롤 가능하도록 구현
            - 선택된 게임 항목은 시각적 피드백 제공

핵심요구사항) 공통 컴포넌트 사용 규칙
            1) 공통컴포넌트 원본을 수정하지 말고, 아래의 props만 활용할 것.
                - variant: primary, secondary를 확인하여 구현할 것.
                - theme: dark 모드만 사용할 것.
                - size: 적절한 크기 설정
                - className 전달: width만 허용할 것.

            2) 적용될 공통컴포넌트 목록을 구현할 것.
                - 검색바: <SearchBar />
                - 확인 버튼: <Button />
                - 취소 버튼: <Button />
                - 오버레이: <Overlay />

핵심요구사항) 모달 동작
            - isOpen이 false이면 렌더링하지 않음 (또는 display: none)
            - ESC 키 누르면 모달 닫기 (선택사항)
            - 오버레이 클릭 시 모달 닫기
            - 모달 내부 클릭 시 닫히지 않도록 처리 (event.stopPropagation)

핵심요구사항) 접근성
            - 적절한 ARIA 속성 제공
            - 키보드 접근 가능 (Tab, Enter, ESC)
            - 포커스 관리 (모달 열릴 때 첫 번째 포커스 요소로 이동)
