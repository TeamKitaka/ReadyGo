==============================================

핵심요구사항) 게임 링크 미리보기 카드 컴포넌트를 구현할 것.

핵심요구사항) Props 타입 정의
            interface GameLinkPreviewProps {
                gameInfo: {
                    app_id: number;
                    name: string;
                    header_image: string | null;
                    short_description: string | null;
                } | null;
                appId: number;
                loading?: boolean;
                onGameStart?: (appId: number) => void;
            }

핵심요구사항) 컴포넌트 구조
            1) 게임 이미지 영역
                - header_image가 있으면 이미지 표시
                - header_image가 없으면 placeholder 표시 (게임 아이콘 또는 기본 이미지)
                - 이미지 로딩 실패 시 placeholder 표시

            2) 게임 정보 영역
                - 게임 이름 (name) 표시
                - 게임 설명 (short_description) 표시
                - short_description이 없으면 생략

            3) 게임 바로 시작 버튼
                - "게임 바로 시작" 또는 "게임 시작" 텍스트
                - 클릭 시 onGameStart(appId) 호출
                - <Button /> 공통 컴포넌트 사용
                - variant: primary 또는 secondary
                - theme: dark 모드만 사용

            4) 로딩 상태 표시
                - loading이 true일 때 로딩 스피너 또는 스켈레톤 표시
                - 게임 정보 대신 로딩 UI 표시

핵심요구사항) 스타일링
            - 색상: global.css에 명시된 CSS 변수 토큰 활용 (하드코딩 금지)
            - 타이포그래피: global.css에 명시된 CSS 변수 토큰 활용 (하드코딩 금지)
            - 카드 스타일: border-radius, padding, background-color 적용
            - 이미지 스타일: 적절한 크기, aspect-ratio 유지
            - 반응형 고려 (선택사항)

핵심요구사항) 공통 컴포넌트 사용 규칙
            1) 공통컴포넌트 원본을 수정하지 말고, 아래의 props만 활용할 것.
                - variant: primary, secondary를 확인하여 구현할 것.
                - theme: dark 모드만 사용할 것.
                - size: 적절한 크기 설정
                - className 전달: width만 허용할 것.

            2) 적용될 공통컴포넌트 목록을 구현할 것.
                - 게임 바로 시작: <Button />

핵심요구사항) 에러 처리
            - gameInfo가 null이면 아무것도 렌더링하지 않음
            - loading이 true이면 로딩 UI만 표시
            - 이미지 로딩 실패 시 placeholder 표시

핵심요구사항) 접근성
            - 적절한 alt 텍스트 제공
            - 키보드 접근 가능 (선택사항)
