핵심요구사항) useChatList.hook.tsx에서 채팅 목록의 안읽음 표시가 실시간으로 업데이트되지 않는 문제를 수정할 것.
            A 채팅방에서 읽음 처리 후 B 채팅방으로 이동한 상태에서, A 채팅방에 새 메시지가 와도 채팅 목록의 안읽음 표시가 실시간으로 업데이트되지 않는 문제를 해결할 것.

            [문제 상황]
            - optimisticReadRoomsRef는 임시 상태이므로, 새 메시지가 오거나 DB의 실제 unreadCount가 증가하면 즉시 해제해야 함
            - 새 메시지가 와도 optimisticReadRoomsRef에 해당 roomId가 있으면 unreadCount를 증가시키지 않음
            - 낙관적 처리가 실제 새 메시지를 무시하게 됨
            - DB에서 조회한 실제 unreadCount가 있어도, optimisticReadRoomsRef에 있으면 무조건 0으로 덮어씀

            [해결 전략]
            - 새 메시지 수신 시 optimisticReadRoomsRef에서 해당 roomId 즉시 제거
            - refresh() 함수에서 DB 실제 unreadCount > 0인 경우 optimisticReadRoomsRef에서 제거 후 실제 값 반영
            - DB 실제 unreadCount === 0이고 optimisticReadRoomsRef에 있는 경우: 낙관적 처리 유지 (0으로 설정)

                    const updatedRooms = rooms.map((room) => {
                      const roomId = room.room.id || 0;
                      const hasOptimisticRead = optimisticReadRoomsRef.current.has(roomId);
                      
                      // 현재 접속 중인 채팅방은 항상 0으로 표시

                      return room;
