            [문제점]
            - 채팅방에 들어가기만 하면 즉시 읽음 처리가 발생하여, 사용자가 메시지를 실제로 읽지 않았는데도 안읽음 표시가 사라짐

            [해결 방안]

            - 메시지 로드 후 자동 읽음 처리 제거
            - 스크롤 기반 읽음 처리 추가: 사용자가 스크롤을 최하단까지 내렸을 때만 읽음 처리
            - 타이머 기반 읽음 처리 추가: 채팅방에 일정 시간(3초) 이상 머물렀을 때 읽음 처리
            - 상대방 메시지 수신 시 읽음 처리 조건 개선: 스크롤이 최하단에 있을 때만 읽음 처리
