구현 결과를 체크리스트로 반환할 것.

==============================================

조건-커서룰) 아래의 커서룰을 적용하여 작업하고, 이 작업이 끝나면 해당 rules 적용 결과를 체크리스트로 반환할 것.
            - @01-common.mdc
            - @02-wireframe.mdc
            - @03-ui.mdc

==============================================

조건-파일경로) 참고할 TSX  파일경로: src/components/party/party.tsx
조건-파일경로) 수정할 CSS  파일경로: src/components/party/styles.module.css
조건-파일경로) 수정할 CSS  파일경로: src/components/party/ui/card/styles.module.css

==============================================

핵심요구사항) 병렬처리 구현을 위한 작업 방식 조건
            - 다른 채팅에서 개발중인 파일을 수정 및 삭제 하지 말 것.
            - 테스트 충돌을 방지하기 위해, 빌드테스트, 전체테스트를 하지 말 것.

핵심요구사항) 다음의 조건에 맞게 파티 게시판 반응형 레이아웃을 step-by-step 으로 구현하고, 적용 결과를 체크리스트로 반환할 것.
            1) 반응형 브레이크포인트
                1-1) 1024px 이하 (태블릿)
                1-2) 768px 이하 (모바일)

            2) 레이아웃 변경사항 (1024px 이하)
                2-1) 컨테이너
                    - 고정 너비 제거 (width: 1336px → max-width: 100%)
                    - 패딩 조정 (32px → 24px)
                
                2-2) 검색 영역 (.searchArea)
                    - 세로 배치로 변경 (flex-direction: column)
                    - gap 조정
                
                2-3) 필터/검색 래퍼 (.filterSearchWrapper)와 새 파티 버튼 (.newPartyButton)
                    - 첫 번째 줄에 나란히 배치 (flex-direction: row)
                    - 각각 적절한 너비 설정
                
                2-4) 검색 입력 (.searchInput)
                    - 두 번째 줄에 전체 너비로 배치
                
                2-5) 탭 영역 (.tabArea)
                    - 세로 배치로 변경 (flex-direction: column)
                    - 탭 래퍼와 정렬 영역을 세로로 배치
                
                2-6) 메인 영역 (.mainArea)
                    - 카드가 1개씩 세로로 배치되도록 변경 (카드 너비: 100%)
                    - gap 조정

            3) 레이아웃 변경사항 (768px 이하)
                3-1) 컨테이너
                    - 패딩 더 줄임 (24px → 16px)
                
                3-2) 콘텐츠 래퍼 (.contentWrapper)
                    - 패딩 조정 (32px → 20px)
                    - border-radius 조정 (36px → 24px)
                
                3-3) 검색 영역 (.searchArea)
                    - gap 조정
                
                3-4) 필터/검색 래퍼 (.filterSearchWrapper)
                    - 세로 배치로 변경 (flex-direction: column)
                    - 게임장르필터와 검색바가 각각 한 줄씩 차지
                
                3-5) 새 파티 버튼 (.newPartyButton)
                    - 전체 너비로 변경
                
                3-6) 탭 영역 (.tabArea)
                    - gap 조정
                
                3-7) 플로팅 버튼 (.floatButton)
                    - 위치 조정 (right: 32px → 16px, bottom: 32px → 16px)

            4) 카드 스타일 변경사항
                4-1) 1024px 이하
                    - 카드 너비를 100%로 변경 (width: 624px → width: 100%)
                
                4-2) 768px 이하
                    - 카드 패딩 조정 (24px → 20px)
                    - 카드 gap 조정 (32px → 24px)

            5) CSS 조건
                5-1) CSS Module만 사용할 것
                5-2) position-absolute 금지, flexbox만 사용할 것
                5-3) 하드코딩된 색상 및 폰트 값 사용 금지, CSS 변수만 사용할 것
                5-4) 기존 레이아웃 구조를 최대한 유지하면서 반응형만 추가할 것

            6) 레이아웃 구조 요약
                6-1) 데스크탑 (기존)
                    [게임장르필터] [검색바] [새파티만들기]
                    [전체파티/참여중인파티] [최신순/마감순]
                    [카드] [카드] [카드] ...
                
                6-2) 태블릿/모바일 (1024px 이하)
                    [게임장르필터] [새파티만들기]
                    [검색바 (전체너비)]
                    [전체파티/참여중인파티]
                    [최신순/마감순]
                    [카드 (전체너비)]
                    [카드 (전체너비)]
                    ...
                
                6-3) 모바일 (768px 이하)
                    [게임장르필터 (전체너비)]
                    [새파티만들기 (전체너비)]
                    [검색바 (전체너비)]
                    [전체파티/참여중인파티]
                    [최신순/마감순]
                    [카드 (전체너비)]
                    [카드 (전체너비)]
                    ...
