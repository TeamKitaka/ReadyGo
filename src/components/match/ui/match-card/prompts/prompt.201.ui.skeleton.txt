핵심요구사항) skeleton card 컴포넌트는 다음의 규칙을 지켜 step-by-step 으로 구현하고, 적용 결과를 체크리스트로 반환할 것.
            - shadcn의 Skeleton 컴포넌트를 사용하여 구현
            - 원본 MatchCard 컴포넌트의 레이아웃과 스타일을 정확히 복사
            - 데이터 로딩 중일 때 표시
            - 실제 MatchCard 컴포넌트의 레이아웃 구조를 반영하여 스켈레톤 구성
              * 아바타 영역 (64px x 64px, 원형)
              * 닉네임 영역 (120px x 24px)
              * 매칭률 영역 (라벨: 50px x 20px, 값: 40px x 20px)
              * 태그 영역 (3개, 각 60px x 24px)
              * 프로필 보기 버튼 (전체 너비 x 48px, border-radius: 99999px)
            - 스켈레톤 카드의 배경색은 실제 카드와 동일하게 var(--color-bg-secondary) 사용
            - 스켈레톤 카드의 border-radius는 실제 카드와 동일하게 24px 사용
            - 스켈레톤 카드의 padding은 실제 카드와 동일하게 32px 사용
            - 스켈레톤 카드의 gap은 실제 카드와 동일하게 적용 (content: 32px, userSection: 11px, userInfo: 16px 등)
            - 반응형 최소 너비 적용
              * 기본: min-width 280px
              * 768px 이하: min-width 260px
              * 480px 이하: min-width 0 (제약 없음)
