# useMatchList Hook 프롬프트

## 개요
매칭 화면용 매칭 목록 조회 React Hook입니다.
필터 옵션 관리와 refetch 기능을 제공합니다.

## 책임
- 매칭 화면용 매칭 목록 조회
- 필터 옵션 관리 (minScore, statusFilter)
- refetch 기능 제공
- 로딩/에러 상태 관리

## 비책임
- API 구현 (API Route에서 처리)
- 비즈니스 로직 (Service에서 처리)
- UI 렌더링 (Component에서 처리)

## 타입 정의

### MatchListOptions
```typescript
export interface MatchListOptions {
  minScore?: number;                    // 최소 매칭 점수 (75-100)
  statusFilter?: 'all' | 'online' | 'offline';  // 상태 필터
}
```

### 반환값
```typescript
{
  results: any[];           // 매칭 결과 배열
  loading: boolean;         // 로딩 상태
  error: Error | null;      // 에러 객체
  refetch: () => void;      // 재조회 함수
}
```

## 사용 예시

### 기본 사용
```typescript
const { results, loading, error, refetch } = useMatchList();
// 기본값: minScore=75, statusFilter='all'
```

### 필터 적용
```typescript
const { results, loading, error, refetch } = useMatchList({
  minScore: 80,
  statusFilter: 'online',
});
```

### 필터 변경 시 자동 재조회
```typescript
const [selectedMatchRate, setSelectedMatchRate] = useState(75);
const [selectedStatus, setSelectedStatus] = useState('all');

const { results, loading, error, refetch } = useMatchList({
  minScore: selectedMatchRate,
  statusFilter: selectedStatus,
});

// 필터 변경 시 useEffect에서 자동으로 재조회됨
```

### 수동 재조회
```typescript
const { results, loading, error, refetch } = useMatchList();

const handleRefresh = () => {
  refetch(); // 수동으로 재조회
};
```

## 구현 세부사항

### fetchMatchList (내부 함수)
**목적**: API 호출 및 상태 업데이트

**처리 흐름**:
1. 로딩 상태 true
2. 에러 상태 null
3. 쿼리 파라미터 생성
4. API 호출 (`/api/match/list`)
5. 응답 처리
6. results 상태 업데이트
7. 로딩 상태 false

**에러 핸들링**:
```typescript
catch (err) {
  setError(err instanceof Error ? err : new Error('Unknown error'));
}
```

### useCallback 사용
```typescript
const fetchMatchList = useCallback(async () => {
  // ...
}, [options.minScore, options.statusFilter]);
```

**의존성 배열**:
- options.minScore
- options.statusFilter

**효과**: 필터 변경 시 함수 재생성 → useEffect에서 재조회

### useEffect 사용
```typescript
useEffect(() => {
  fetchMatchList();
}, [fetchMatchList]);
```

**효과**: fetchMatchList 변경 시 자동 재조회

## 상태 관리

### results
- **타입**: `any[]`
- **초기값**: `[]`
- **업데이트**: API 응답 성공 시

### loading
- **타입**: `boolean`
- **초기값**: `false`
- **true**: API 호출 중
- **false**: API 호출 완료 (성공/실패)

### error
- **타입**: `Error | null`
- **초기값**: `null`
- **업데이트**: API 호출 실패 시

## 사용 흐름
1. 컴포넌트에서 useMatchList 호출 (옵션 전달)
2. useEffect에서 fetchMatchList 자동 호출
3. API 호출 → 로딩 상태 true
4. 응답 받음 → results 업데이트 → 로딩 상태 false
5. 필터 변경 시 → fetchMatchList 재생성 → useEffect 재실행
6. 사용자가 refetch 호출 → fetchMatchList 수동 호출

## 홈 화면 Hook과의 차이점
| 구분 | useHomeMatches | useMatchList |
|------|----------------|--------------|
| **API** | /api/match/results | /api/match/list |
| **옵션** | 없음 | minScore, statusFilter |
| **개수** | 4개 | 12개 |
| **캐시** | 무제한 | 5분 TTL |
| **refetch** | 제공 안 함 | 제공 |
