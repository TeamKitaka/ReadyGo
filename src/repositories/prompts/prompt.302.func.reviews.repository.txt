핵심요구사항) 리뷰 기능을 위한 Repository를 구현하고, 적용 결과를 체크리스트로 반환할 것.

            ❗ 전제 조건
                - chatRoomMembers에서 두 개의 유저 아이디를 받아서 사용할 것.
                - reviewer_id(리뷰를 쓰는 사람)와 target_user_id(리뷰받는 사람)에 배치할 것.
                - 각각 후기를 작성하게 할 것.
                - reviews 테이블을 사용할 것.

            1) Repository 기본 구조
                1-1) Supabase 클라이언트 사용
                    - src/lib/supabase/server.ts의 supabaseAdmin을 사용할 것.
                    - import 경로: import { supabaseAdmin } from '@/lib/supabase/server';
                
                1-2) 타입 정의
                    - database.types.ts의 Database 타입을 활용할 것.
                    - reviews 테이블의 Row, Insert, Update 타입을 활용할 것.
                    - 커스텀 타입이 필요한 경우 파일 내부에 정의할 것.

                1-3) 에러 처리
                    - 모든 함수는 error가 발생하면 throw error할 것.
                    - steamGame.repository.ts의 패턴을 따를 것.
                
                1-4) 권한/RLS 전제 조건
                    - Repository는 supabaseAdmin(service role)을 사용하므로 RLS를 우회한다.
                    - 리뷰 작성 권한 검증은 호출부(API Route 또는 Hook)에서 선행되어야 한다.
                    - Repository 함수는 순수한 데이터 액세스 로직만 담당한다.

            2) 리뷰 조회 함수 (SELECT)
                2-1) getReviewsByReviewer(reviewerId: string, limit: number = 50, offset: number = 0): Promise<Review[]>
                    - 특정 사용자가 작성한 리뷰 목록을 조회할 것.
                    - reviews 테이블 사용할 것.
                    - 조건:
                        - reviewer_id = reviewerId
                        - created_at 기준 내림차순 정렬 (최신 리뷰가 먼저)
                    - limit과 offset을 사용하여 페이지네이션 지원할 것.
                    - 반환 타입: database.types.ts의 reviews.Row[] 타입 활용.

                2-2) getReviewsByTarget(targetUserId: string, limit: number = 50, offset: number = 0): Promise<Review[]>
                    - 특정 사용자가 받은 리뷰 목록을 조회할 것.
                    - reviews 테이블 사용할 것.
                    - 조건:
                        - target_user_id = targetUserId
                        - created_at 기준 내림차순 정렬 (최신 리뷰가 먼저)
                    - limit과 offset을 사용하여 페이지네이션 지원할 것.
                    - 반환 타입: database.types.ts의 reviews.Row[] 타입 활용.

                2-3) getReviewById(reviewId: number): Promise<Review | null>
                    - 특정 리뷰 ID로 리뷰를 조회할 것.
                    - reviews 테이블 사용할 것.
                    - 조건: id = reviewId
                    - 리뷰가 없으면 null을 반환할 것.
                    - 반환 타입: database.types.ts의 reviews.Row | null 타입 활용.

                2-4) getReviewsBetweenUsers(userId1: string, userId2: string): Promise<Review[]>
                    - 두 사용자 간의 상호 리뷰를 조회할 것.
                    - reviews 테이블 사용할 것.
                    - 조건:
                        - (reviewer_id = userId1 AND target_user_id = userId2)
                        - OR (reviewer_id = userId2 AND target_user_id = userId1)
                    - created_at 기준 내림차순 정렬할 것.
                    - 반환 타입: database.types.ts의 reviews.Row[] 타입 활용.

            3) 리뷰 작성 함수 (INSERT)
                3-1) createReview(params: CreateReviewParams): Promise<Review>
                    - 리뷰를 작성할 것.
                    - reviews 테이블에 레코드 생성할 것.
                    - 파라미터 타입:
                        - reviewer_id: string (리뷰를 쓰는 사람)
                        - target_user_id: string (리뷰받는 사람)
                        - score_manner: number (매너 점수, 1-5 또는 적절한 범위)
                        - score_teamwork: number (팀워크 점수, 1-5 또는 적절한 범위)
                        - score_communication: number (소통 점수, 1-5 또는 적절한 범위)
                        - comment: string | null (후기 내용, 선택사항)
                    - insert 필드:
                        - reviewer_id: 전달받은 reviewer_id
                        - target_user_id: 전달받은 target_user_id
                        - score_manner: 전달받은 score_manner
                        - score_teamwork: 전달받은 score_teamwork
                        - score_communication: 전달받은 score_communication
                        - comment: 전달받은 comment (null 가능)
                        - created_at: 현재 시간 (Supabase 자동 설정)
                    - 생성된 리뷰 정보를 반환할 것.
                    - 반환 타입: database.types.ts의 reviews.Row 타입 활용.

            4) 타입 정의
                4-1) 커스텀 타입 정의
                    - Review: database.types.ts의 reviews.Row 활용.
                    - CreateReviewParams: 리뷰 작성 시 필요한 파라미터 타입
                        - reviewer_id: string
                        - target_user_id: string
                        - score_manner: number
                        - score_teamwork: number
                        - score_communication: number
                        - comment?: string | null

                4-2) 함수 파라미터 타입
                    - 모든 함수의 파라미터는 명시적 타입을 지정할 것.
                    - uuid 타입은 string으로 처리할 것.
                    - bigint 타입은 number로 처리할 것.

            5) 구현 주의사항
                5-1) Supabase 쿼리 패턴
                    - .from()으로 테이블 선택.
                    - .select()로 필요한 컬럼만 선택 (성능 최적화).
                    - .eq(), .in(), .or() 등으로 필터링.
                    - .order()로 정렬.
                    - .limit(), .range()로 페이지네이션.
                    - .insert()로 생성.
                    - .single()로 단일 레코드 조회.

                5-2) 조인 쿼리
                    - Supabase의 .select()에서 관계된 테이블 조인 가능.
                    - 예: .select('*, user_profiles(*)')
                    - 또는 별도 쿼리로 분리하여 처리.

                5-3) 에러 처리
                    - 모든 Supabase 쿼리 결과에서 error 체크할 것.
                    - error가 존재하면 throw error할 것.
                    - try-catch는 호출하는 쪽(Hook 등)에서 처리할 것.

                5-4) 테이블 사용 규칙
                    - ✅ reviews 테이블만 사용할 것.
                    - ✅ reviewer_id와 target_user_id를 활용하여 양방향 리뷰 지원.
