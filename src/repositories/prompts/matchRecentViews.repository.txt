# Match Recent Views Repository 프롬프트

## 개요
match_recent_views 테이블에 대한 데이터 접근 계층입니다.
프로필 조회 이력을 기록하고 조회하여 중복 방지 기능을 지원합니다.

## 책임
- match_recent_views 테이블 CRUD
- 프로필 조회 이력 관리
- 순수 DB 접근만 담당

## 비책임
- 비즈니스 로직 (Service에서 처리)
- 데이터 변환 (ViewModel에서 처리)

## 주요 함수

### findByViewer
**목적**: 최근 N시간 내 조회한 target_user_id 조회

**파라미터**:
- client: Supabase 클라이언트
- userId: 기준 유저 ID
- hours: 조회할 시간 범위 (시간 단위)

**반환값**: 최근 조회한 target_user_id 목록

**사용 예시**:
```typescript
const { data: recentViews } = await findByViewer(client, userId, 24);
// 24시간 이내 조회한 사용자 목록
```

**주의사항**:
- 중복 방지 로직에서 24시간 기준으로 사용됨
- match_exposure_log (4시간)와 함께 사용

### insert
**목적**: 프로필 조회 이력 기록

**파라미터**:
- client: Supabase 클라이언트
- userId: 기준 유저 ID
- targetUserId: 조회한 대상 유저 ID

**반환값**: 삽입된 레코드

**사용 예시**:
```typescript
await insert(client, userId, targetUserId);
// 프로필 조회 시점에 기록
```

**호출 시점**:
- 사용자가 다른 사용자의 프로필을 클릭/조회할 때
- Side Panel에서 프로필 상세 조회 시

### deleteOldRecords
**목적**: 오래된 조회 이력 정리 (Cron용)

**파라미터**:
- client: Supabase 클라이언트
- days: 삭제할 기준 일수 (기본값: 30일)

**반환값**: 삭제 결과

**사용 예시**:
```typescript
await deleteOldRecords(client, 30);
// 30일 이상 된 조회 이력 삭제
```

## 테이블 스키마
```sql
CREATE TABLE match_recent_views (
  id BIGSERIAL PRIMARY KEY,
  user_id UUID,
  target_user_id UUID,
  viewed_at TIMESTAMPTZ
);
```

## 인덱스
- 조회 최적화를 위한 인덱스 필요 (user_id, viewed_at DESC)

## 중복 방지 로직에서의 역할
```typescript
// getMatchList.service.ts에서 사용
const [{ data: recentViews }, { data: recentExposures }] = await Promise.all([
  matchRecentViewsRepo.findByViewer(client, viewerId, 24), // 24시간 조회 이력
  matchExposureLogRepo.findRecentByViewer(client, viewerId, 4), // 4시간 노출 이력
]);

const excludeIds = new Set([
  ...(recentViews?.map((v) => v.target_user_id) || []),
  ...(recentExposures?.map((e) => e.target_id) || []),
]);
```

**차이점**:
- **match_recent_views**: 프로필을 실제로 조회한 이력 (24시간)
- **match_exposure_log**: 매칭 목록에 노출된 이력 (4시간)

## 사용 흐름
1. 사용자가 프로필 클릭 → insert로 조회 이력 기록
2. 매칭 목록 조회 시 → findByViewer로 최근 24시간 조회 이력 확인
3. 조회한 사용자는 매칭 목록에서 제외 (중복 방지)
4. 주기적으로 deleteOldRecords로 오래된 이력 정리 (Cron)
